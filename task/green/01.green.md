```
[P] 당신은 Python TDD 학습 프로젝트에서 GREEN 단계 최소 구현을 수행하는 시니어 Python 엔지니어입니다.

    - 현재 실패 원인: ModuleNotFoundError (entity/boundary 패키지 부재)
    - 목표: 기존 tests/ 를 수정하지 않고 assert 기준으로 전부 pass
    - 계약 Source of Truth: doc/PRD.md §3.2·§3.3·§6, README.md, .cursorrules
    - RED 산출물: tests/entity/ 2파일, tests/boundary/ 3파일, conftest.py, helpers.py

[T] 아래 최소 구현만 추가하여 GREEN을 달성하세요.

    ## 1) 패키지 골격 (import 해소)

    entity/
      __init__.py
      errors.py
      unit_registry.py
      conversion_engine.py

    boundary/
      __init__.py
      cli_input_parser.py
      output_formatter.py
      error_presenter.py

    ## 2) entity/errors.py

    - class DomainError(Exception):
        - 속성: code: str, message: str | None = None
        - DUPLICATE_UNIT 등 PRD error code 문자열 사용

    ## 3) entity/unit_registry.py

    - class UnitRegistry:
        - register(unit_id: str, meters_per_unit: float) -> None
          - 동일 unit_id 재등록 시 DomainError(code="DUPLICATE_UNIT")
        - get_meters_per_unit(unit_id: str) -> float
          - 미등록 시 KeyError 또는 DomainError (boundary UNKNOWN_UNIT과 연동만 되면 됨)

    ## 4) entity/conversion_engine.py

    - @dataclass ConversionRow:
        - target_unit: str
        - target_amount: float   # raw, 반올림 전

    - class ConversionEngine:
        - __init__(registry: UnitRegistry)
        - convert_all(source_unit: str, source_amount: float) -> list[ConversionRow]
          - 등록된 모든 unit_id에 대해 1행씩 (행 수 = Registry 등록 수)
          - 환산식 (단일 경로, if-elif 분기 금지):
            target = source × factor(source) ÷ factor(target)
            factor = registry.get_meters_per_unit(unit_id)
          - feet↔yard 직접 상수 금지

    ## 5) boundary/cli_input_parser.py

    - class InputValidationError(Exception):
        - 속성: code: str (DomainError와 동일 패턴)

    - class CliInputParser:
        - __init__(registry: UnitRegistry)
        - parse(line: str) -> object  # 성공 시 ParsedConvert 등 (성공 TC 없음 — 시그니처만 타입 힌트)

    검증 순서 권장 (한 줄에 하나의 실패만):
      1) len(line) >= 257 → INPUT_TOO_LONG
      2) ':' 없음 → MALFORMED_INPUT
      3) split(':', 1) → unit_id, amount_text
      4) float 파싱 실패 → NON_NUMERIC
      5) amount < 0 → NEGATIVE_VALUE
      6) unit_id not in registry → UNKNOWN_UNIT (예: cubit:1)

    ## 6) boundary/output_formatter.py

    - class OutputFormatter:
        - format_table(
            source_unit: str,
            source_amount: float,
            conversions: list[ConversionRow],
          ) -> list[str]

    규칙 (PRD F-04):
      - 각 줄: "{source_amount} {source_unit} = {target_display} {target_unit}"
      - LHS amount·unit은 인자 그대로 (2.5, 3.28084 — float str() 결과 허용)
      - target만 소수 1자리 half-up (Decimal ROUND_HALF_UP 권장)
      - meter:2.5 → "2.5 meter = 8.2 feet", "2.5 meter = 2.7 yard" 포함
      - 줄 수 = len(conversions) == 3 (default registry)

    ## 7) boundary/error_presenter.py

    - class ErrorPresenter:
        - __init__(stream: TextIO = sys.stderr)
        - present(code: str, **context: str) -> int
          - stderr 출력 형식 (tests 정규식·문자열 일치):
            code: {CODE}
            message: {MESSAGE}
          - exit code 반환: 입력·변환 실패 = 1

    메시지 매핑 (PRD F-02, tests/boundary/test_error_presenter.py 와 일치):
      | code | message |
      |------|---------|
      | MALFORMED_INPUT | Invalid format. Use unit:value (ex: meter:2.5) |
      | NON_NUMERIC | Invalid number: {amount_text} |
      | NEGATIVE_VALUE | Value must be non-negative: {amount_text} |
      | UNKNOWN_UNIT | Unknown unit: {unit_id} |
      | INPUT_TOO_LONG | Input exceeds 256 characters |

[F] 완료 조건 (반드시 실행·보고)

    1) 테스트 파일·assert·기대 error code 는 변경하지 말 것 (REG-05)
    2) entity 레이어: open/print/subprocess/stdin/stdout 사용 금지
    3) feet↔yard 직접 비율 상수·ConversionEngine if-elif unit 분기 금지
    4) 아래 명령 실행 후 결과 요약:

       py -3 -m pytest tests/entity/ -v
       py -3 -m pytest tests/boundary/ -v
       py -3 -m pytest tests/ -v

    5) GREEN 판정:
       - exit code 0
       - 수집 TC 전부 pass (ImportError 없음, assert 실패 0건)
       - RED 때와 달리 "assert 기준" green 임을 명시

    6) 구현 범위: control/, data/, config/, CLI main 은 이번 턴 제외
```

## 수치·반올림 참고 (테스트 통과용)

| 검증 | raw (entity) | table 표시 (boundary) |
|------|----------------|------------------------|
| meter:2.5 → feet | 8.2021 | 8.2 |
| meter:2.5 → yard | 2.734025 | 2.7 |
| feet:1 → meter | 0.3048 | (해당 TC는 LHS만 검증) |

**half-up 1자리 예시 (Python):**

```python
from decimal import Decimal, ROUND_HALF_UP

def format_target(amount: float) -> str:
    return str(Decimal(str(amount)).quantize(Decimal("0.1"), rounding=ROUND_HALF_UP))
```
