## 2. 기능 요약

### 2.1 API (`decaying_unit.py`)

| 함수 | 시그니처 | 의미 |
|------|----------|------|
| `registerUnit` | `(unit_id: str, ratio: float) -> None` | `1 unit_id = ratio` meter |
| `convert` | `(source_unit, amount, target_unit) -> float` | meter 허브 경유 (시그니처 고정) |
| `convertAll` | `(source_unit, amount) -> dict[str, float]` | 등록 전 단위 → 환산값 맵 |

### 2.2 구현 접근 (OCP)

- 기존 `entity.UnitRegistry` · `entity.ConversionEngine` **재사용** (신규 if-else 분기 없음)
- `registerUnit` → `register_from_ref(unit_id, ratio, "meter")`
- `ratio <= 0` → `ValueError` (BT-04)
- 파라미터화 테스트 간 **동일 cubit 중복 등록** → idempotent 처리

### 2.3 검증 예시 (cubit)

| 연산 | 기대값 (tol 1e-5) |
|------|-------------------|
| cubit→meter (1.0) | 0.4572 |
| meter→cubit (1.0) | 1/0.4572 ≈ 2.1872 |
| cubit→feet (1.0) | 0.4572 × 3.28084 ≈ 1.4997 |
