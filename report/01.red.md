## 3. 테스트 계약 요약

### 3.1 Entity (`tests/entity/`)

| TC | invariant / PRD | 기대 |
|----|-----------------|------|
| 기본 등록 | §3.3 Background | meter=1.0, feet=3.28084, yard=1.09361 (EPS) |
| 중복 등록 | F-03 | `meter` 재등록 → `DomainError.code == DUPLICATE_UNIT` |
| `meter:2.5` | F-01, M-02 | feet≈8.2021, yard raw≈2.734025 |
| `feet:1` 역변환 | M-02 | meter≈0.3048 (EPS) |

환산식(테스트가 전제):  
`target = source × MetersPerUnit(source) ÷ MetersPerUnit(target)`

### 3.2 Boundary (`tests/boundary/`)

| 입력 예 | `code` | exit |
|---------|--------|------|
| `meter` | `MALFORMED_INPUT` | 1 |
| `meter:2.5.3` | `NON_NUMERIC` | 1 |
| `meter:-1` | `NEGATIVE_VALUE` | 1 |
| `cubit:1` | `UNKNOWN_UNIT` | 1 |
| 257자 이상 | `INPUT_TOO_LONG` | 1 |

**table 포맷**

- 모든 줄 LHS = 사용자 입력 (`2.5 meter`, `3.28084 feet`)
- target 1자리 half-up: `8.2 feet`, `2.7 yard`
- 줄 수 = 등록 단위 수 (3)

**stderr (ErrorPresenter)**

```
code: {CODE}
message: {MESSAGE}
```

메시지는 PRD F-02 표와 정규 일치.
