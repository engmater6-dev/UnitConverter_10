### 9.3 TC 작성 팁 (AI + 학습자 협업)

1. **Invariant 먼저 표로 고정** — 3.28084 / 1.09361 / NEG-01 / UNKNOWN_UNIT 을 RED 파일 상단 주석에 적고 TC ID를 붙인다.  
2. **Dual-Track 분리** — 파싱 실패는 `tests/boundary/`, 환산은 `tests/entity/`, `tests/red/`는 게이트만 유지한다.  
3. **RED는 의도적 FAIL 한 줄** — `pytest.fail("RED")` 대신 GREEN 전환 시 **assert 한 곳만** 바꿔 커밋 메시지와 1:1 매핑한다.  
4. **Golden Master는 stdout 전체** — 단위 테스트 assert와 GM baseline을 이중으로 두면 REFACTOR 안전망이 된다.  
5. **cov Miss → 계약 TC** — `error_presenter` 82% 같은 파일은 «예외 타입 × code × exit» 파라미터화가 효율적이다.  
6. **AI에게「테스트만」명시** — REFACTOR·cov 단계에서 프로덕션 diff 폭주를 막는다.
