## 3. 공통점

- **Dual-Track:** Domain(`entity/`) vs Boundary(`boundary/`) 분리
- **비율:** 1 meter = 3.28084 feet · 1 meter = 1.09361 yard
- **EPS:** PRD §3.3 (`1e-9` 절대·상대)
- **대표 입력:** `meter:2.5`, `feet:3.28084`, `meter:-1`, `cubit:1`, `meter:2.5.3`
- **fixture:** `default_registry`

- 비교·참고용으로만 사용 권장

## 9. API·계약 불일치 요약 (통합 시 주의)

| 항목 | `red_temp` 가정 | 현재 `tests/` + 구현 |
|------|-----------------|----------------------|
| 파서 예외 | `InputValidationError` + code | `ValueError` / `DomainError` 혼용 |
| `convert_all` 시그니처 | `source_unit=`, `source_amount=` | `(source_unit, amount)` 위치 인자 |
| ErrorPresenter | `present(code, **context)` | `present(Exception)` / `code_for` |
| OutputFormatter | 인자 3개 분리 | `ConversionResult` 리스트 |
| Registry fixture | 수동 `register()` | `DEFAULT_METERS_PER_UNIT` 내장 |

GREEN/REFACTOR 시 **한쪽 계약으로 통일** 후 `tests/red/` assert를 채우는 것이 안전하다.
